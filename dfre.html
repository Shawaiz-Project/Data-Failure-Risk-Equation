Data Failure Risk Equation — Complete Reference

A bounded, nonlinear risk score for joint data/AI degradation. v5.0 unifies every feature from v3 (Intelligent) and v4 (Autonomous) into one production-ready library.

Overview

Data pipelines rarely fail for a single reason. Missing values, invalid records, distribution drift, and model uncertainty combine into something worse than any single signal suggests. DFRE quantifies that combined risk as a bounded score 𝓡 ∈ [0, 1).

core equation 
𝓡 = 1 − exp( −[ M + V + D + U + λ(MV+VD+DU+UM) + γ·MVDU ] / (1 + √N) )

M Missingness

Fraction of missing expected values in the batch.

V Invalidity

Fraction of records failing validation rules.

D Drift

Normalized distribution shift vs. reference.

U Uncertainty

Normalized predictive uncertainty of the model.

Quick Start

Add DFRE risk scoring to any pipeline in a single line.

python 
import dfre

# One line — that's it
result = dfre.score(
    missing=0.08,
    invalid=0.04,
    drift=0.12,
    uncertainty=0.20,
    n=1000,
)

print(result.risk)      # 0.0914
print(result.band)      # LOW
print(result.action)    # continue_normal_monitoring

Architecture

2

3

4

5

Design principle: DFRE is a monitoring layer, not a replacement. Keep the raw M, V, D, U signals alongside the risk score so you can diagnose why risk rose.

Learned Coefficients v3

3.1

Input-dependent λ and γ

Intelligent

Instead of fixed scalar λ and γ, learn them as neural functions λ(M,V,D,U) and γ(M,V,D,U) from historical batches. This makes the interaction strength context-aware — a 5% drift may be critical in a sensitive pipeline but negligible in a stable one.

python 
from dfre.learned import train_learned_dfre, LearnedDFREModel

# Train on historical batches
model = train_learned_dfre(history_df, epochs=200, lr=1e-3)
wrapper = LearnedDFREModel(model)

# Score with learned coefficients
result = wrapper.score(M=0.30, V=0.20, D=0.40, U=0.35, n=5000)
print(result.risk, result.learned_lam, result.learned_gamma)

# Save / load
wrapper.save("dfre_learned_v5.pt")
wrapper = LearnedDFREModel.load("dfre_learned_v5.pt")

Why it matters

  • Context-aware: Different pipelines get different interaction strengths.
  • Data-driven: λ, γ become learned parameters, not hyperparameters.
  • Backward compatible: Falls back to static λ=1, γ=1 when no model loaded.

Bayesian Uncertainty v3

3.2

Credible intervals over 𝓡

Intelligent

Propagate input distributions and parameter posteriors through the equation to get a full posterior over 𝓡. Essential for regulated industries that require uncertainty quantification.

python 
from dfre.bayesian import BayesianDFRE

bayes = BayesianDFRE(
    lam_posterior=("normal", 1.0, 0.15),
    gamma_posterior=("normal", 1.0, 0.25),
)

posterior = bayes.score(
    M_dist=("beta", 2, 20),
    V_dist=("beta", 1, 30),
    D_dist=("beta", 2, 15),
    U_dist=("beta", 4, 10),
    n=5000,
    credible_level=0.95,
)

print(f"𝓡 = {posterior.mean:.3f} ± {posterior.std:.3f}")
print(f"95% CI: [{posterior.ci_low:.3f}, {posterior.ci_high:.3f}]")

Supported distributions

TupleDistributionParameters
("normal", μ, σ)Normalmean, std
("uniform", a, b)Uniformlow, high
("beta", α, β)Betaalpha, beta
("point", v)Diracvalue

Causal DFRE v3

3.3

Intervention ranking via do-calculus

Intelligent

Answer "what would happen if we fixed missingness?" DFRE uses a causal DAG over {"M", "V", "D", "U", "F"} and estimates the risk reduction from each single-variable intervention.

python 
from dfre.causal import CausalDFRE

causal = CausalDFRE().fit(history_df)

effects = causal.rank_interventions({"M": 0.35, "V": 0.20, "D": 0.30, "U": 0.40})
for e in effects:
    print(f"Fix {list(e.intervention)[0]}: Δrisk = {e.expected_risk_reduction:.3f}")

# Fix M: Δrisk = 0.243  ← largest impact
# Fix D: Δrisk = 0.187
# Fix U: Δrisk = 0.121
# Fix V: Δrisk = 0.089
Note: Causal claims require a valid DAG. The default DAG is a reasonable starting point, but you should validate edges against domain knowledge.

Temporal DFRE v3

3.4

Sequence-aware scoring with LSTM

Intelligent

DFRE normally treats each batch independently. Real pipelines have temporal dependencies — yesterday's drift predicts today's uncertainty. Temporal DFRE aggregates over a rolling window using a bidirectional LSTM.

python 
from dfre.temporal import TemporalDFRE
import torch

model = TemporalDFRE(window=10, hidden=64, layers=2)

# Feed the last 10 batches
window = torch.tensor(last_10[["M","V","D","U"]].values).unsqueeze(0)
current = torch.tensor([current_batch[["M","V","D","U"]].values])

risk = model(window, current, n=len(current_batch))
print(risk.item())

Multi-modal Signals v3

3.5

Text, image, embedding signals

Intelligent

Extend DFRE beyond tabular data. Extract M, V, D, U from text, images, and embedding spaces.

TextMissingnessSignal

Missing-token rate for NLP pipelines.

ImageCorruptionSignal

Blur/NaN detection via Laplacian variance.

EmbeddingDriftSignal

MMD-based drift over embedding spaces.

TokenUncertaintySignal

Per-token entropy from LLM logits.

python 
from dfre.signals.multimodal import (
    TextMissingnessSignal, ImageCorruptionSignal,
    EmbeddingDriftSignal, TokenUncertaintySignal,
)

M = TextMissingnessSignal().compute(texts)
V = ImageCorruptionSignal(blur_threshold=100).compute(images)
D = EmbeddingDriftSignal(reference_embeddings=ref).compute(current_emb)
U = TokenUncertaintySignal().compute(logits)

Auto-Calibration v3

3.6

Rolling-window recalibration

Intelligent

Continuously re-fit λ, γ, and thresholds from a rolling window of recent batches. Runs on a schedule or is triggered when drift is detected.

python 
from dfre.calibration.auto import AutoCalibrator

calibrator = AutoCalibrator(window_days=90, min_samples=200)

# On every batch, record the snapshot + eventual outcome
calibrator.observe(snapshot, outcome=1)

# Weekly: recalibrate
result = calibrator.recalibrate()
# {
#   "status": "ok",
#   "lam": 1.15,
#   "gamma": 0.92,
#   "auc": 0.87,
#   "thresholds": {"low": 0.18, "moderate": 0.41, "high": 0.68},

Fused Uncertainty v3

3.8

Drift-weighted uncertainty

Intelligent

Combine base model uncertainty with drift-driven uncertainty. If the input distribution has drifted, the model's predictions are less trustworthy even if its output entropy is low.

python 
from dfre.signals.fused_uncertainty import FusedUncertaintySignal
from dfre.signals import UncertaintySignal, DriftSignal

U_fused = FusedUncertaintySignal(
    base_estimator=UncertaintySignal("entropy"),
    drift_signal=DriftSignal(["age", "bmi"], scale=0.25),
    drift_weight=0.4,
)

U = U_fused.compute(probabilities, reference_batch, current_batch)

Agentic DFRE v4

4.1

Autonomous, self-healing pipelines

Autonomous

DFRE becomes an autonomous agent that not only detects risk but takes corrective action: alert, quarantine, retrain, or rollback. All actions are logged for audit.

python 
from dfre.agentic import DFREAgent, AgentPolicy, Action, handlers

def handle_quarantine(snapshot, result):
    return {"quarantined_batch": snapshot.batch_id, "risk": result.risk}

agent = DFREAgent(
    policy=AgentPolicy(
        risk_thresholds={"alert": 0.20, "quarantine": 0.45,
                         "retrain": 0.55, "rollback": 0.75},
        dry_run=False,
    ),
    action_handlers={
        Action.QUARANTINE: handle_quarantine,
        Action.RETRAIN: handlers.retrain_handler,
    },
)

snapshot = dfre.make_snapshot(0.30, 0.30, 0.40, 0.50, 1000)
result = dfre.score(0.30, 0.30, 0.40, 0.50)
agent.act(snapshot, result)
# → {"action": Action.QUARANTINE, "executed": True, "result": {...}}

Available actions

ActionTriggerDefault behavior
CONTINUE𝓡 < 0.20Do nothing
ALERT0.20 ≤ 𝓡 < 0.45Notify channel
QUARANTINE0.45 ≤ 𝓡 < 0.55Hold batch
RETRAIN0.55 ≤ 𝓡 < 0.75Trigger retrain
ROLLBACK𝓡 ≥ 0.75Rollback model
Human-in-the-loop: By default, ROLLBACK requires manual approval. Configure require_human_for in AgentPolicy to change this.

Federated DFRE v4

4.2

Privacy-preserving multi-tenant

Autonomous

Multiple tenants collaborate on DFRE calibration without sharing raw data. Each client computes gradients locally; the server aggregates them.

python 
from dfre.federated import FederatedDFREServer, FederatedDFREClient

server = FederatedDFREServer(initial_lam=1.0, initial_gamma=1.0, lr=0.1)

clients = [
    FederatedDFREClient("tenant_a", history_a),
    FederatedDFREClient("tenant_b", history_b),
    FederatedDFREClient("tenant_c", history_c),
]

for round_i in range(50):
    updates = [c.compute_local_update(server.lam, server.gamma) for c in clients]
    server.aggregate(updates)

print(f"Global λ = {server.lam:.3f}, γ = {server.gamma:.3f}")
Compliance: Raw tenant data never leaves the client. Only gradient vectors are transmitted — GDPR / HIPAA friendly.

Migration Guide

v2 → v3

  • dfre.score() now returns DFREResult — use .risk attribute.
  • Default lam, gamma can be None (auto-learned) — pass explicit values for v2 behavior.
  • DriftSignal.statistic default changed to "auto" — pass explicit "psi" for v2 behavior.

v3 → v4

  • DFREAgent is opt-in — old code works unchanged.
  • Streaming API introduces StreamingDFRE — batch API unchanged.
  • Federated learning is opt-in.

v4 → v5

  • All v3 and v4 features are now unified — no breaking changes from either.
  • Single pip install "dfre[all]" gets everything.
  • Optional dependencies remain optional.
